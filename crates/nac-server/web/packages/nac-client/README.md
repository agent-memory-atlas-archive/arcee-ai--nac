# Experimental NAC client artifact (ALL-121)

This package is the revision-pinned, registry-free artifact used to prove the
ALL-121 ArceeFM journey. It is not the final packaging decision tracked by
ALL-122 and is deliberately marked private to prevent registry publication.

Install an exact reviewed NAC commit with npm:

```json
{
  "dependencies": {
    "@arcee-ai/nac-client-all-121": "git+https://github.com/arcee-ai/nac.git#<full-commit-sha>"
  }
}
```

Commit the resulting `package-lock.json`; npm records the resolved full Git
revision. The package has no runtime dependencies or install scripts. Its
checked-in `dist/` output is built from `src/`, and its OpenAPI subset is
generated by NAC's existing `make generate-api-contract` writer.

The root export contains `NacClient`, `NacTransport`, the command-admission and
error contracts, snapshot/replay behavior, `subscribeToSessionEvents`, the
auth-capable `EventSourceFactory` seam, and only the transitive OpenAPI schemas
required by those APIs.
